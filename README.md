# Within-hosts to Between-hosts

This repo contains the code used in the paper *Using virtual patients to parametrise an age-of-infection model* by Clotilde Djuikem, Morgan Craig, Kang-Ling Liao, Stéphanie Portet and Julien Arino.

## Content of the repository
- CODE contains the code itself, a mixture of `R` and `julia`.
- FIGS contains the figures generates using this code.
- OUTPUT is distributed empty (save for a README.md file) but is used by the different scripts when running the code.
